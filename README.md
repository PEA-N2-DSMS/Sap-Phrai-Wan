# แผนที่ลาดตระเวนทรัพย์ไพรวัลย์

วงจร WGT03VR-105 · ฟีดเดอร์ 3

ภาพสำรวจ 48 รูป แสดง 47 หมุด และข้อมูลแบบฟอร์ม 45 รายการ พิกัดอ่านจากข้อความในภาพ รูปที่ 2 เป็นภาพแทรกลูกถ้วยรั่วของจุดที่ 1 และใช้พิกัดเดียวกับรูปที่ 1 รายการ Excel แสดงตามต้นฉบับ

ภาพดาวเทียมใช้ Esri World Imagery แต่ละหมุดเปิดตำแหน่งใน Google Maps ได้

## เปิดใช้งาน

- เปิด `index.html` ในเบราว์เซอร์ที่เชื่อมต่ออินเทอร์เน็ต
- สำหรับ GitHub Pages ให้เลือก Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save
